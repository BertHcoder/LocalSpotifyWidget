🔑 Connect to Spotify

One-time setup, takes about two minutes. Spotify only lets tools like this one in through a small developer app that you create yourself. It's free to create, but since February 2026 Spotify requires the account that owns it to have Spotify Premium.

  1. Open the Spotify Developer Dashboard

    Log in with the Spotify account you play music on, and accept the developer terms if asked.

    Open the dashboard ↗
  2. Click Create app and fill in the form
    • App name and description: anything you like, e.g. My OBS Widget
    • Redirect URI: copy this exactly, paste it and click Add
    • Which API/SDKs are you planning to use: tick Web API

    Accept the terms and click Save.

  3. Copy the Client ID

    It's shown on your new app's page. You only need the Client ID, not the Client secret.

  4. Log in with Spotify

    Spotify asks you to allow access. Click Agree and you'll come straight back here.

📋 Add the widget to OBS

  1. Copy the widget URL
  2. Add a Browser source in OBS

    Click + under Sources, choose Browser, give it a name and click OK.

  3. Paste the URL and set the size

    Paste it in the URL field, set Width to 400 and Height to 120, then click OK. Drag it wherever you like in your scene.

💡 Tip: In the OBS Browser Source properties, enable "Refresh browser when scene becomes active" so the widget picks up new settings automatically without needing to clear the cache.
💡 If changed settings are not showing in OBS, right-click the browser source and click "Refresh cache of current page".
